## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Build:** Gradle (KTS)
- **Database:** Room
- **Ads:** Google AdMob
- **Backend/Config:** Firebase (Remote Config, Analytics)
- **PDF:** PdfBox-Android / iText
- **AI:** Gemini API
- **Architecture:** MVVM, ViewModel, Coroutines/Flow

# PDF Editor

Android PDF editor app.

## Features

- Merge PDF
- Split PDF
- Compress PDF
- Organize Pages
- Extract Pages
- Crop PDF
- Watermark
- Page Numbering
- Bates Numbering
- Annotate PDF
- Fill & Sign
- Flatten PDF
- Repair PDF
- Compare PDF
- PDF to Image / Image to PDF
- PDF to ZIP
- Scanner
- AI Tools (Summarize, Chat)
- Voice Reader
- Metadata Editor
- Print
- Web to PDF
- QR to PDF
- Imposition
- Premium / Settings / History

## Play Store

- Direct link: https://play.google.com/store/apps/details?id=com.villagefast.pdfeditor
- Developer account: https://play.google.com/store/apps/dev?id=VillageFast
